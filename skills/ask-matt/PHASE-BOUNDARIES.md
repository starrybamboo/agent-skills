# Collaboration and context

Choose collaboration based on dependencies, shared state, available tools, and coordination cost. Continue with the current context while it remains useful.

- When delegating, provide the objective, relevant sources, working state, and expected result. Make overlapping work and shared-state operations explicit to the participants.
- Create a user-visible task only at the user's request.
- Use `/handoff` when responsibility moves or a fresh context would help. Preserve decisions, current state, valid evidence, remaining work, and the next action.
- After automatic compaction, continue from the preserved state and verify uncertain pointers as needed.

Check how combined changes satisfy the outcome, reusing valid evidence and focusing additional checks on integration risks.
